# JSX transformer for Leaner.js

Plugin for Vite/Rollup/Rolldown which transforms JSX files for Leaner.js.


## Getting Started

Documentation: https://leanerjs.org/


## Development

To build the package:

```bash
npm run build
```

To run tests:

```bash
npm test
```
